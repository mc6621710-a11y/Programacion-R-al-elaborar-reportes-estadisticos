# Programacion-R-al-elaborar-reportes-estadisticos
Programación R al elaborar reportes estadísticos

en este repositorio se encuentran los programas solicitados las respectivas tablas de resultado de los progamas y 2 bases de datos que se alimentaron artificalmente para simular las ventas una incluye custumers y la otra incluye solo las ventas por pais y año 

todos los progamas fueron probados y testeados en r studio y funcionales buscando no generar errores se agregaron validacion para cuando el archivo no este cargado 

cada archivo lleva el nombre de cada programa solicitado con su respectivas tablas que generaron en cvs 

prop_sales_by_country_by_year_month  genera la tabla prop_sales_by_country_by_year_month.csv
prop_changes_sales_by_country_by_year_month genera la tabla prop_changes_sales_by_country_by_year_month.csv
histogram_avg_sales_customer crea el histograma histogram_avg_sales_customer.png
"top_10_performance_stores_by_country genera el grafico top_10_performance_stores_by_country.png
